# Public image preparation

- `dashboard-*-demo.jpg`: screenshots of the actual dashboard UI rendered locally with clearly labelled synthetic data. No live home settings were loaded.
- `hardware-clockwise.png`: original hardware photograph rotated exactly 90 degrees clockwise, losslessly saved without original metadata. No AI redrawing.
- `telegram-alert-redacted.png`: built-in image editor; prompt: preserve the technical alert, cover all personal names, addresses, landmarks, phone numbers and event/account identifiers with fully opaque redaction bars, including faint header text.
- `telegram-phone-notification-redacted.png`: built-in image editor; prompt: preserve the FireGuard notification and technical scores, irreversibly cover the complete home-name/address/landmark paragraph and carrier/account details, and invent no replacement private values.
- `telegram-camera-snapshot-redacted.png`: opaque text masks applied directly to the supplied screenshot. The original camera photograph and person are retained exactly, following the user's explicit instruction. A pixel comparison verifies the photo rectangle is unchanged. Header/account details and the surrounding private home/address/landmark text are hidden.

The two AI-edited examples are illustrations of supplied captures, not exact unaltered evidence. The camera-snapshot image is not the AI-generated version that concealed the person; that rejected variant is excluded. Original private attachments are not committed. Published files are flattened, and original metadata is removed.
